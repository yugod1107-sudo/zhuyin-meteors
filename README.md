# 注音隕石 · 保衛星球

為小學一年級設計的注音鍵位與看字拼音練習。純 HTML、CSS、JavaScript，不需安裝套件或登入。目前先在本機試玩，尚未發布。

## 試玩

直接用瀏覽器開啟 `index.html`，或使用本機預覽網址。

開始前可設定隕石速度：0.5、1、1.5、2、3 倍，預設為 1.5 倍。畫面會顯示目前難度與學習模式下的落地秒數，設定會保存在本機。隕石會在 0.7 秒內完整進場，再依所選速度下降；「停住慢慢練」仍會停住隕石。

遊戲區擴大，砲塔縮至原尺寸的 65%，砲管轉向與雷射起點同步調整。

### 兩種學習模式

- **注音鍵位**：英文輸入模式；看到單一注音，按對應鍵。也能點螢幕鍵盤。
- **看字拼音**：英文輸入模式；隕石只顯示國字，不顯示拼音、不提示下一鍵。自行依序輸入完整注音與聲調，每個正確按鍵射擊一次，最後一發才擊碎隕石。例如「麵」依序按 `A → U → 0 → 4`（ㄇ、ㄧ、ㄢ、ˋ），共射擊四次。一聲按空白鍵，二聲 `6`、三聲 `3`、四聲 `4`。按錯不射擊，保留已完成進度。點另一顆隕石可以切換目標，也可使用畫面上的注音鍵盤。

看字拼音題庫包含 120 個不重複的繁體生活單字，分「自然天地」「動物朋友」「家人與生活」「校園學習」「食物點心」「日常動作」六類，每類 20 字。題庫採各情境的常用讀音，本版尚未加入詞語及多音字辨義教學。新手模式可以勾選「停住慢慢練」。

每組題庫洗牌後依序出題，整組出完才重新洗牌；同一頁面按「再玩一次」會接續尚未出過的字。重新整理頁面會重新洗牌。新手每回合仍為 10 題，並非將整組題庫一次做完。

看字拼音隕石使用加大的國字，下方只顯示完成步數，不顯示注音答案。舊版「注音拼音」「中文打字」設定會自動轉為看字拼音。

- 新手練習：1 顆隕石、20 秒落地，完成 10 顆，不扣生命。
- 小小挑戰：最多 2 顆、15 秒落地、90 秒、5 格護盾。
- 太空高手：最多 3 顆、10 秒落地、90 秒、3 格護盾。
- 上述掉落時間為鍵位模式在 1 倍速度的基準；看字拼音時間乘 1.5，再除以所選速度倍率。
- 隕石從上方不同位置進場，往左下或右下斜落，會優先選擇不擁擠的路線；注音保持正向。
- 按對注音時，星球砲塔轉向目標，從砲口射出雷射，再顯示命中光圈與散開火花。連續答對會依序射擊；暫停會凍結射擊動畫，最後一發播放完才顯示成績。
- 鍵位模式可選聲母、介音與韻母、全部或自選符號。完整拼音模式包含題庫使用的一至四聲。
- 按錯不扣護盾，漏接才扣；長按不重複計分；切換分頁或離開視窗自動暫停。
- 正確率＝接受的正確按鍵數 ÷（正確＋錯誤按鍵數）；漏接另列。
- 每顆 10 分，每 5 連擊額外 10 分；最高分依學習模式、聲調設定、是否停住、難度和題庫分開儲存在此瀏覽器。
- 設定與最高分僅存在本機瀏覽器，不會上傳，不會跨裝置同步。

## 發布至 GitHub Pages

1. 在 GitHub 建立公開儲存庫 `zhuyin-meteors`。
2. 將此資料夾內的 `index.html`、`styles.css`、`meteors.css`、`learning.css`、`word-groups.js`、`curriculum.js`、`game.js`、`assets` 資料夾、`.nojekyll`、`README.md` 上傳至儲存庫根目錄。
3. 在 Settings → Pages 選擇 Deploy from a branch，選 `main`、`/ (root)`，儲存。
4. 等待 GitHub 完成部署。預計網址為 `https://yugod1107-sudo.github.io/zhuyin-meteors/`，以 GitHub 顯示的實際網址為準。

所有路徑均為相對路徑，支援 GitHub Pages 專案子路徑。隕石圖片隨專案附上，沒有外部字型、分析追蹤或網路依賴。玩法參考花蓮縣打字練習網的掉落消除類型；本專案程式與介面獨立撰寫。
